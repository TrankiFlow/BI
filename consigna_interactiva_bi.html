Análisis de Ventas

Esta etapa del trabajo práctico integrador se centrará en el análisis de datos de ventas para una empresa de e-commerce. A través de diversas etapas, se aplicarán los conceptos de Business Intelligence utilizando Google Sheets desde la recolección y limpieza de datos, hasta la creación de informes sencillos.

Descargar Datasets

1 Etapa 1: Fundamentos y Calidad

Obligatorio (Clases 1 a 4)

Objetivo: Comprender los conceptos básicos de BI y evaluar la calidad de los datos de ventas.

Captación del cliente

Diseñar un breve informe (en Google Docs) que explique la importancia de la aplicación de BI para un e-commerce. Incluir ejemplos de herramientas de BI, cómo las va a utilizar y los beneficios para el negocio.

Investigación Ética/Legal

Realizar un caso de estudio sobre una violación de ética en datos en el ámbito del comercio electrónico nacional o internacional. Elaborar un informe analizando el contexto, las faltas y las consecuencias, así como las lecciones aprendidas y errores a evitar.

Búsqueda de fuentes

Identificar tres fuentes públicas de datos relacionadas con el e-commerce, como estadísticas sobre ventas en línea o datos de comportamiento del consumidor. Crear una tabla que resuma cada fuente con enlaces, tipos de datos y potencial de análisis.

Obtención de datos

Importar el conjunto de datos de ventas a Google Sheets. Crear un formulario con el checklist de criterios de calidad de datos y aplicar el checklist al conjunto de datos, registrando los hallazgos en un informe breve.

2 Etapa 2: Preparación y Análisis

Obligatorio (Clases 5 a 8)

Objetivo: Procesar y analizar los datos de ventas para extraer insights relevantes.

Limpieza y preparación

Utilizar funciones de Google Sheets para limpiar y normalizar los datos. Documentar el proceso de limpieza.

Integración de datos

Utilizar funciones para combinar fuentes de datos y crear una única estructura de datos que incluya información relevante de ambos.

Análisis exploratorio

Calcular los valores de estadística descriptiva (media, mediana, moda, desviación estándar) sobre las ventas mensuales utilizando Google Sheets. Presentar los hallazgos en gráficos (barras o líneas) y un breve análisis.

Informe preliminar

Crear un informe en Google Sheets que contenga un análisis de ventas contando con tablas y gráficos que representen los hallazgos. Seguir los principios para obtener una visualización efectiva.

¿Cómo utilizar las tablas?

  • Análisis de Ventas: Relacionar Ventas, Clientes y Productos a través de `ID_Cliente` e `ID_Producto` para extraer insights.
