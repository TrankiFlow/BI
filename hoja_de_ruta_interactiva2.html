¿Te trabaste armando una base maestra desde múltiples fuentes?

Si tenés tablas separadas de clientes, productos y ventas:

  1. Limpiá cada tabla por separado.
  2. Utiliza funciones como =BUSCARV para cruzar los datos clave en una única tabla final.
  3. Dejá documentado el paso a paso de esa integración en tu Gsheets auxiliar.

Lo que vimos en la Clase 4 (Conceptos clave):

  • Validación de datos: consiste en establecer reglas para evitar errores al momento de cargar información. Por ejemplo, permitir solo fechas válidas, limitar valores numéricos a un rango esperado o usar listas desplegables para categorías.
  • Estandarización: implica unificar formatos para que los datos sean consistentes. Por ejemplo, usar un mismo formato de fecha, escribir las categorías siempre de la misma manera o definir criterios comunes para nombres, códigos y unidades.
  • Estandarización: implica unificar formatos para que los datos sean consistentes. Por ejemplo, usar un mismo formato de fecha, escribir las categorías siempre de la misma manera o definir criterios comunes para nombres, códigos y unidades.
  • Revisión de datos faltantes: permite identificar campos vacíos que pueden afectar el análisis. En algunos casos se podrán completar; en otros, habrá que decidir si corresponde excluir esos registros o aclarar la limitación.
  • Detección de duplicados: ayuda a evitar que una misma persona, venta, producto o registro aparezca más de una vez y distorsione los resultados.
  • Auditoría o revisión de muestras: consiste en revisar una parte del conjunto de datos para detectar errores frecuentes y evaluar si la información es confiable.
  • Documentación de cambios: permite registrar qué modificaciones se hicieron sobre los datos, por qué se hicieron y quién las realizó. Esto mejora la transparencia y la trazabilidad del trabajo.
  • Preservación de la fuente original: antes de limpiar o modificar datos, es recomendable conservar una copia intacta del archivo original. De esta manera, siempre se puede volver a la fuente inicial si aparece un error o una duda.
